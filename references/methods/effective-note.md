# Effective Note

> Internal method reference for `xhs-monetization-skill`. This file is not an independent Skill.

**Use when:** 要写或改标题、封面、正文、评论区与交易型笔记

**Scope:** 标题、封面、正文、评论区与交易型内容

**Method intent:** 设计和优化以商业结果为目标的小红书笔记，包括有效爆款标准、五段转化漏斗、标题、封面、正文、价值交付和评论区承接。

## Use when
- 要写一篇小红书笔记。
- 要把普通笔记改成更能带来咨询/成交的笔记。
- 要诊断“为什么有赞藏但不赚钱”。
- 要批量建立标题、封面、正文模板。

## Definition: 有效爆款
商业运营应区分“爆款”和“有效爆款”。商业账号最终关注的不是热闹，而是目标用户是否被找到、需求是否被唤起、是否触发咨询或购买。

因此评价笔记时，同时看流量和交易信号。

## Funnel
按以下链路检查：

**被看见 → 被点击 → 被互动 → 被咨询 → 成交/进入可交易关系。**

对应指标：

- 搜索结果/曝光能力
- 点击率
- 互动率
- 咨询率
- 咨询到交易路径的转化率

每一环都会产生乘法式损耗，所以不要只优化某一环。

## Four creation formulas
可用四套框架理解：

1. **爆款 = 人群需求 + 表现形式 + 互动理由**
2. **爆款 = 引起兴趣 + 挖掘痛点 + 解决问题**
3. **爆款 = 选题 + 标题 + 封面 + 正文**
4. 内容结果存在随机性，应通过正确方法、重复测试和数据复盘提高成功概率。

## Procedure

### 1. 先写任务卡
在创作前回答：

- 这篇给谁看？
- 承接什么需求？
- 用户为什么点开？
- 看完得到什么？
- 希望用户做什么？
- 这个动作为什么对用户有价值？

### 2. 标题
常见类型：

- 对话型
- 数字型
- 痛点型
- 干货型
- 悬念型
- 反差型
- 互动型

标题优化检查：

- 给出明确阅读预期
- 指定或暗示目标身份
- 重要信息前置
- 自然包含核心关键词
- 语气与内容匹配，不夸大、不虚假

### 3. 封面
三个原则：

1. **提示内容和打开理由**：让用户低成本知道这篇讲什么。
2. **提供丰富信息点**：合集、清单、攻略等可在封面预告信息密度。
3. **美观和质感**：清晰、整洁、一致；美感是加分，但信息传达优先。

### 4. 正文
正文结构：**开头—中间—结尾**。

- 开头：承接标题预期，尽早出现主题/关键词，解释“为什么值得继续看”。
- 中间：交付信息或情绪价值，用序号、分隔、短段落降低阅读成本；表达尽量自然、可读。
- 结尾：完成目的承接，例如提出可回答的问题、补充身份/经验、引导查看相关内容或使用合规的官方承接方式。

可进一步归纳为：**承接预期 + 引入痛点 + 描述情景 + 解决方案 + 互动理由**。

### 5. 三层价值
至少明确交付一种：

- **实用价值**：节省时间、提供知识、清单、攻略、方法。
- **情绪价值**：共鸣、向往、治愈、认同、有趣。
- **决策价值**：对比、测评、避坑、教程、选择建议；通常更接近交易。

### 6. 评论区承接
把评论区当笔记的一部分：

- 回答高频疑问
- 补充正文未覆盖的信息
- 把真实用户问题沉淀为下一批选题
- 给出清楚、合规的下一步动作

不要通过伪造用户评论或虚假反馈制造社会证明。

## Output format
当用户要求创作时，输出：

1. 目标人群与需求
2. 选题理由
3. 3-5 个标题候选
4. 封面信息结构
5. 正文
6. 评论区 FAQ / 承接建议
7. 这篇笔记对应的漏斗指标

## QA checklist
发布前逐项检查：

- 目的明确吗？
- 是目标用户真实关心的问题吗？
- 标题/封面能在几秒内传达价值吗？
- 正文真的解决问题吗？
- 有实用/情绪/决策价值吗？
- 用户知道下一步可以做什么吗？
- 是否有夸大、虚假、侵权或当前平台违规风险？
