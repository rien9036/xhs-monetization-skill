# Strategy & Positioning

> Internal method reference for `xhs-monetization-skill`. This file is not an independent Skill.

**Use when:** 不知道做什么账号、卖什么、商业目标或定位不清

**Scope:** 商业目标、交易路径、账号定位与对标研究

**Method intent:** 为小红书商业账号制定目的、量化目标、交易路径、对标研究、商业定位和账号表达；适用于从0到1规划、转型或定位不清的账号。

## Use when
用户出现以下任一情况时使用：

- “我想做小红书，但不知道做什么。”
- 有业务但不知道小红书应该承担什么角色。
- 有爆款/粉丝但没有咨询或成交。
- 账号内容分散、目标人群不清楚。
- 要评估某个赛道是否值得做。

## Core principle
先做商业判断，再做内容动作。项目闭环是：**目的→目标→策略→执行→复盘**；账号运营优先级是：**定位>选题>内容>引流**。

## Inputs
尽量收集：

- 用户现有产品、服务、能力或资源
- 目标收入/获客目标与时间范围
- 可投入的人、时间、预算、账号数量
- 想服务的人群
- 已有账号或同类账号信息
- 预期变现方式：产品、服务、广告、店铺、电商等

信息不全时，可以先用可验证假设输出，但要标明假设。

## Procedure

### 1. 明确目的和量化目标
把“想做流量”改写成可管理目标，例如：

“在某时间内，以某资源投入，通过小红书获得某类需求/咨询，并最终实现某商业结果。”

不要以“涨粉”自动替代商业目标。粉丝只是链路中的中间变量。

### 2. 明确交易路径
回答：

- 卖什么？
- 谁会付钱？
- 在哪里成交？
- 用户从看到笔记到付费，要经过哪些节点？
- 哪个节点最容易流失？

### 3. 做商业定位四象限交集
依据四个维度：

- **平台需要**：内容是否能给平台带来停留、互动和优质供给。
- **用户需求**：需求是否真实、有规模、有价值、可交付。
- **同行验证**：是否已有账号验证需求和交易闭环；不要只看赞藏，要看需求型评论和成交迹象。
- **资源能力**：用户是否具备专业、产品、交付、时间、团队或供应链等条件。

最终定位应回答：**以什么身份，用什么内容形式，找到什么人群的什么需求，交付什么产品/服务。**

### 4. 拆解对标账号
坚持“学习可以学习的、学习值得学习的”。

至少拆：

- 昵称、头像、简介、背景
- 内容主题、标题、封面、排版
- 核心需求和关键词
- 爆款是否带来需求型评论
- 交易/交付路径
- 制作成本和可复制性
- 账号体量是否与自己可比

不要默认对标头部 IP；优先选择资源、体量、变现模式更接近自己的账号。

### 5. 设计账号表达
好的商业账号表达应尽量做到：

- **真实**：身份、经历、能力和案例可支撑。
- **垂直**：让用户和算法快速知道账号属于什么领域。
- **信任**：用简短信息表达专业、经验、资源、结果或品牌证明。
- **直接**：用户进入主页后能迅速理解“你是谁、你做什么、我为什么继续看”。

### 6. 输出定位语句
使用：

“这是一个面向【目标人群】，解决【核心需求】，以【身份/内容形式】持续提供【价值】，最终通过【产品/服务/商业模式】完成变现的账号。”

## Output format
输出：

1. 目的与量化目标
2. 交易路径
3. 平台需要 / 用户需求 / 同行验证 / 资源能力
4. 推荐定位与不推荐定位
5. 账号主页表达建议
6. 3-5 个对标研究方向
7. 下一步需要构建的需求图谱

## Diagnostic rules
- 有爆款、无咨询：先检查选题是否承接交易需求，再检查账号信任和交易路径。
- 有粉丝、无成交：不要继续把涨粉当核心指标，回到产品和需求匹配。
- 内容杂乱：优先收窄定位而不是提高更新频率。
- 对标账号很强但不可复制：更换“可学习”的腰部/新兴/同资源账号。
