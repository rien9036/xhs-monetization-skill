# AI Content Workflow

> Internal method reference for `xhs-monetization-skill`. This file is not an independent Skill.

**Use when:** 要用 AI 辅助需求分析、选题、标题或内容生产

**Scope:** AI 辅助需求分析、选题与内容生产

**Method intent:** 用 AI 辅助小红书定位、需求分析、标题和正文生产；采用角色、术语、标准、案例、反馈的迭代流程，并要求事实与经验由用户或可靠来源提供。

## Use when
- 要批量生成标题、选题或笔记初稿。
- 要把已有爆款结构转成可复用提示流程。
- 要让 AI 更懂某个细分行业。

## Five-step workflow
推荐使用以下 AI 协作流程：

**设定角色 → 明确含义 → 确认标准 → 提供案例 → 调教反馈。**

把它转换为以下执行方式。

### 1. 设定角色
指定 AI 正在完成的具体工作，而不是只说“你是小红书专家”。

应包含：领域、人群、商业目的和产出类型。

### 2. 明确含义
把业务术语、产品特点、目标人群、用户痛点解释清楚。AI 不应自行虚构用户没有提供的真实经历、资质、效果或数据。

### 3. 确认标准
先给质量标准，再生成：

- 目标人群是否清楚
- 是否解决真实需求
- 是否包含关键词
- 是否符合账号定位
- 是否有信息/情绪/决策价值
- 是否存在夸大和违规风险

### 4. 提供案例
给 3-10 个用户认可的案例，让 AI 提炼“结构特征”，不要要求直接改写或复制他人内容。

### 5. 调教反馈
指出具体问题：

- 太泛
- 太营销
- 缺关键词
- 缺数字/例子
- 不像真实经验
- 不符合目标人群
- 结尾动作不清楚

然后只修改对应部分。

## Recommended pipeline
AI 最适合辅助：

- 需求发散
- 关键词聚类
- 选题组合
- 标题候选
- 内容结构
- 多版本表达
- 发布前自检

AI 不应替代：

- 真实体验
- 产品事实
- 资质/案例证明
- 当前平台政策核验
- 用户评论和数据真实性

## Output format
当用户要求“给我一个可复用提示模板”时，生成一个包含：背景、目标人群、产品事实、需求、关键词、内容标准、禁止事项、输出格式、反馈回路的模板。
