# Demand & Topic Map

> Internal method reference for `xhs-monetization-skill`. This file is not an independent Skill.

**Use when:** 不知道写什么、用户需求/关键词/长尾词不清

**Scope:** 需求图谱、关键词、长尾词与选题池

**Method intent:** 从目标人群需求、搜索关键词、已验证爆款、评论和跨平台内容中建立需求图谱与选题库，并按商业价值和可执行性排序。

## Use when
- 不知道每天写什么。
- 选题靠临时灵感。
- 笔记有内容但需求不强。
- 希望批量生产稳定选题。
- 要建立关键词库、长尾词库或对标爆款库。

## Core principle
核心原则：**选题比“怎么写”更重要**。先研究需求，再生产内容；尽量把调研做在发布第一篇笔记之前。

## Inputs
- 目标人群
- 产品/服务
- 核心交易需求
- 用户常见痛点
- 当前可观察到的搜索词、评论、对标笔记或第三方数据

## Procedure

### 1. 建立需求图谱
尽量完整穷尽目标用户在购买前、中、后会遇到的问题：

- 想知道什么？
- 害怕什么？
- 会比较什么？
- 会搜索什么？
- 哪些决策成本高？
- 哪些问题最接近购买？

将每个需求映射到可能的搜索词。

### 2. 需求图谱选题法
可以从这些信号找需求：

- 搜索栏下拉词
- 搜索结果中的相关搜索/标签
- “猜你想搜”“搜索发现”等平台推荐信号
- 对标爆款评论区里的高频问题
- 电商/交易平台已经提炼出的产品语言
- 第三方趋势或关键词工具

注意：具体入口名称可能变化，应以当前平台为准。

### 3. 爆款重复选题法
原则：**复用已验证需求，不复制原文。**

研究同领域及跨平台已验证内容，提炼：

- 需求
- 角度
- 信息结构
- 情绪触发
- 决策问题
- 关键词

然后换成自己的事实、案例、数据、表达形式和目标人群。

### 4. 组合公式选题法
使用组合思路：热点、群体、情感、价值、地域等元素两两或多项组合。

例如：
- 群体 + 价值
- 地域 + 情感 + 价值
- 热点 + 群体 + 决策

组合的目的不是堆元素，而是让一个需求获得更明确的“为什么现在要看”。

### 5. 给选题打分
至少按以下维度排序：

- 需求规模
- 交易意图
- 竞争供给
- 可交付价值
- 与账号定位一致度
- 可制作性
- 长尾价值

高搜索、高决策、高匹配、可交付的题优先。

### 6. 形成选题池
建议分层：

- A：交易型/决策型，直接关联咨询或购买
- B：搜索型/实用型，承接稳定需求
- C：情绪型/互动型，用于扩大触达和人设
- D：品牌/故事型，用于建立信任

可以先准备大量行业选题，再筛选高分题；具体数量不是硬规则，关键是先筛再写。

## Output format
输出表格字段：

- 人群
- 需求/痛点
- 搜索词
- 选题
- 内容类型
- 商业意图
- 预期互动
- 优先级
- 可用证据/案例

最后给出“下一批最值得写的 10 个题”。

## Rules
- 不只追热点；交易型账号必须保留决策型和搜索型题。
- 不把“原创”理解为从零发明需求；可以研究成熟需求，但必须独立创作。
- 评论区高频问题是需求信号，但单个评论不能直接代表市场规模。
