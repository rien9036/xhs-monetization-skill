# Traffic & Growth

> Internal method reference for `xhs-monetization-skill`. This file is not an independent Skill.

**Use when:** 流量、搜索、点击、互动或涨粉不理想

**Scope:** 搜索、推荐、互动、涨粉与付费放大判断

**Method intent:** 诊断和提升小红书搜索、推荐、互动与涨粉效率；围绕关键词、相关性、内容权重、转粉理由和付费放大建立可测试的增长方案。

## Use when
- 笔记浏览低、搜索找不到。
- 有浏览但点击低。
- 有赞藏但不涨粉。
- 想做 SEO、关键词布局、搜索长尾。
- 想判断是否值得付费放大。

## Traffic model
主要流量来源可概括为：关注、发现/推荐、搜索。对商业型账号尤其重视搜索流量，因为搜索行为通常带着更明确的需求。

具体流量占比、推荐池大小和产品入口会变化，不应把历史数字直接用于当前判断。

## Procedure

### 1. 判断卡在哪一层
按漏斗：

- 没曝光 → 需求/关键词/相关性/收录问题
- 有曝光没点击 → 选题/标题/封面问题
- 有点击没互动 → 内容价值和预期不匹配
- 有互动不涨粉 → 账号定位、持续价值、人设/信任不足
- 有互动无咨询 → 需求离交易太远或承接不清楚

### 2. 搜索 SEO
核心原则：有搜索就有 SEO。

把目标搜索词自然布局在：

- 标题
- 正文关键位置
- 标签/话题
- 图片可读文字（如适用）
- 评论补充（如真实相关）

不要机械堆词。优先“主关键词 + 细分长尾词”的组合，并让整篇内容真实围绕关键词回答问题。

### 3. 相关性和内容权重
可将搜索表现理解为账号与笔记多种信号共同作用的结果，重点可执行项包括：

- 原创和真实
- 账号垂直
- 内容质量和互动
- 稳定活跃
- 关键词相关度
- 话题/标签匹配
- 避免违规和侵权

具体权重公式是平台内部机制，不应声称掌握精确算法。

### 4. 涨粉
可把涨粉拆成“内容流量 × 转粉能力”的组合，重点包括：

- 垂直定位
- 真实人设
- 稳定风格
- 持续价值

用户关注的本质是相信“未来继续看这个账号有价值”。因此主页和系列内容要给持续预期。

### 5. 互动
互动是反馈信号，但互动不是目标本身。优先通过真实价值获得：

- 收藏：有长期使用价值
- 评论：存在表达、提问、决策或讨论需求
- 转发：内容值得分享给别人
- 关注：账号具备持续价值
- 私信/咨询：用户需要更深层解决方案

不要通过刷量、互助造假或伪造评论制造数据。

### 6. 付费放大
原则：**放大值得放大的流量**。

投放前先确认：

- 自然流量已有正向反馈
- 点击、互动或咨询中至少有一项显著优于账号基线
- 交易价值或目标指标能被测量
- 有小预算测试和止损标准

使用当前平台可用的官方投放产品；具体产品能力、门槛和规则必须先核验。

## Output format
- 当前卡点
- 证据
- 优先级最高的 3 个优化动作
- 关键词/内容调整
- 主页/转粉调整
- 付费测试条件（若适用）
- 下一轮应观察的数据
