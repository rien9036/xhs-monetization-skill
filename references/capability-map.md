# Capability Map

本仓库只有一个 Skill：`xhs-monetization-skill`。下表均为该 Skill 的内部方法，不是独立 Skill。

| Internal method | Trigger | Scope | Reference |
|---|---|---|---|
| `strategy-positioning` | 不知道做什么账号、卖什么、商业目标或定位不清 | 商业目标、交易路径、账号定位与对标研究 | `references/methods/strategy-positioning.md` |
| `demand-topic-map` | 不知道写什么、用户需求/关键词/长尾词不清 | 需求图谱、关键词、长尾词与选题池 | `references/methods/demand-topic-map.md` |
| `effective-note` | 要写或改标题、封面、正文、评论区与交易型笔记 | 标题、封面、正文、评论区与交易型内容 | `references/methods/effective-note.md` |
| `traffic-growth` | 流量、搜索、点击、互动或涨粉不理想 | 搜索、推荐、互动、涨粉与付费放大判断 | `references/methods/traffic-growth.md` |
| `monetization-design` | 有流量但不赚钱，或要设计服务/广告/电商路径 | 服务、广告、电商等变现路径与单位经济 | `references/methods/monetization-design.md` |
| `operations-diagnostics` | 要诊断账号、做日控/周复盘或找漏斗卡点 | 账号诊断、日控、复盘与实验设计 | `references/methods/operations-diagnostics.md` |
| `ai-content-workflow` | 要用 AI 辅助需求分析、选题、标题或内容生产 | AI 辅助需求分析、选题与内容生产 | `references/methods/ai-content-workflow.md` |
