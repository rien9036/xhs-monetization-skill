# Core Frameworks

## 1. 项目闭环
目的 → 目标 → 策略 → 执行 → 复盘

## 2. 运营优先级
定位 > 选题 > 内容 > 引流

## 3. 商业定位
平台需要 + 用户需求 + 同行验证 + 资源能力

## 4. 有效笔记漏斗
被看见 → 被点击 → 被互动 → 被咨询 → 成交/进入交易关系

## 5. 有效爆款四个理解框架
- 人群需求 + 表现形式 + 互动理由
- 引起兴趣 + 挖掘痛点 + 解决问题
- 选题 + 标题 + 封面 + 正文
- 结果有随机性，应通过正确方法与重复测试提高成功概率

## 6. 三种选题法
- 需求图谱
- 已验证爆款需求复用
- 热点/群体/情感/价值/地域等组合

## 7. 正文结构
开头：承接预期
中间：交付价值
结尾：承接目的

可进一步理解为：承接预期 + 引入痛点 + 描述情景 + 解决方案 + 互动理由。

## 8. 内容三层价值
实用价值 / 情绪价值 / 决策价值

## 9. 涨粉四因素（质性）
垂直定位 / 真实人设 / 稳定风格 / 持续价值

## 10. 变现五步
战略定位 → 交易路径 → 账号定位 → 有效笔记 → 承接交易

## 11. 需供比
同时看需求规模和内容/账号供给，不把“看起来冷门”自动等于蓝海。

## 12. 付费原则
只放大已经被自然反馈证明值得放大的内容。
